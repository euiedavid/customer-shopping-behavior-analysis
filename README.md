# Customer Shopping Behavior and Sales Analysis

An end-to-end exploratory data analysis (EDA) of customer shopping behavior and sales performance. This project covers data cleaning, customer demographics, purchasing activity, sales analysis, and product category analysis to identify key customer segments and purchasing patterns.

## Business Problems Addressed

- Which customer groups contribute the most to total sales?
- Do different age groups show differences in purchasing activity?
- Which occupations have the highest average purchase amounts?
- How do sales differ across gender, marital status, state, and geographic zone?
- Which product categories generate the highest total sales?
- Are certain product categories more represented among particular age groups?
- Which customer groups and product categories should the company pay particular attention to?

## Project Overview

This project analyzes customer shopping behavior and sales performance using Python and exploratory data analysis (EDA). The analysis examines customer demographics, purchasing activity, transaction amounts, geographic segments, occupations, and product categories to identify patterns in customer behavior and sales performance.

The findings are used to identify key customer groups and product categories that can support more targeted marketing and sales strategies.

## Data Analysis Experience

This project provided hands-on experience in the following data analysis tasks:

- Data cleaning and quality assessment
- Missing-value handling
- Duplicate-value detection
- Data type inspection and validation
- Univariate and bivariate exploratory data analysis
- Descriptive statistical analysis
- Data grouping and aggregation using Pandas
- Customer segmentation by demographic and geographic attributes
- Sales and purchasing behavior analysis
- Percentage and distribution analysis
- Correlation analysis
- Data visualization using Matplotlib and Seaborn
- Interpretation of analytical findings
- Translating data insights into business recommendations

## About the Dataset

The dataset used in this project is the Diwali Sales Data featured in Rishabh Mishra's Python Diwali Sales Analysis tutorial.

The original dataset and tutorial notebook are available in the Python Diwali Sales Analysis GitHub repository.
